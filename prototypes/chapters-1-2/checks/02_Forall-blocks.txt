234: Trial2.practice ANSWER pre def left_inverse_of_right_inverse (A B : Type) (f : A → B) (g : B → A) (hf : ∀ x y : A, f x = f y → x = y) (hfg : ∀ y : B, f (g y) = y) : ∀ x : A, g (f x) = x := fun x => hf (g (f x)) x (hfg (f x))
235: Trial2.practice ANSWER p 比べたい二つの対象は g (f x) と x である。それらに f を適用した結果の等式 f (g (f x)) = f x は、hfg (f x) が与える。この証明を単射性に渡せばよい。等号の書き換えをせず、二つの仮定の適用で証明できる。
