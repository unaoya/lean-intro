87: Intro1.functions  h3 fun 記法 — 関数を項として書く
88: Intro1.functions  p 関数そのものを書くには、fun という記法を使える。引数 x が使えるものとして項 e を書くと、そこから一つの項 fun x => e を作れる。これは「x を受け取って e を返す関数」を表す。 => の右側の項 e を、関数の本体（body）と呼ぶ。
89: Intro1.functions  p 例えば、x : Nat を使って書いた項 x + x から、関数の項 fun x => x + x を作る。本体には、受け取った x を使える。
90: Intro1.functions  p 注意 — 名前を書く場所と、項を書く場所。 この形の x は引数の名前を書く場所であり、任意の項を入れる場所ではない。名前は n などに変えてよく、その場合は本体でその引数を指す名前も揃える。fun x => x + x と fun n => n + n は同じ関数を表す。一方、e の場所には、その引数を使って組み立てた項を書く。
91: Intro1.functions  p 注意 — 記法を作る記号。 fun と => は、それ自体が項なのではない。これらは、引数の名前と本体を組み合わせて関数の項を作るための特別な記号である。全体の fun x => e が一つの項になる。
92: Intro1.functions  p この教材の表示設定では、出力中の => が ↦ と表示される。同じ関数の書き方である。
