# 第1〜5章 改稿試作

元の原稿からコピーして編集した相談用の版です。
第1〜5章は本番の `dev/src/` に移行しました。以後の本文の修正は `dev/src/`、
スライドの調整は `dev/slides/` で行います。このディレクトリは移行前の比較用に残しています。

- `src/`: 移行前の試作の本文と解答。
- `originals/`: コピーした時点の元原稿10ファイル。比較と、元の補足の保存に使います。
- `slides/`: 試作だけに適用するページ境界と表示段階。
- `preview/`: 通読版・スライド版HTML。生成物です。
- `preview/reference/`: 第3・4章の元原稿の通読版。補足の前後の定義も確認できます。
- `output/pdf/`: 試作の通読版・スライド版PDF（Git管理外）。
- `checks/`: Lean検査と表示確認の結果。
- `original-sha256.json`: 試作開始時の正本全Leanファイルのハッシュ。

## 再生成

リポジトリ直下から実行します。

```sh
python3 -B prototypes/chapters-1-2/build.py
```

改稿した本文・解答10ファイルをLeanで検査してから、通読版とスライド版を `preview/` に生成します。
Leanのコンパイル結果は試作内の `.build/` に置きます。
HTML生成器とスライド用CSS/JavaScriptは、既存の `dev/tools/` を読み込んで利用します。
元原稿・公開中の `docs/`・正本のスライド設定は変更しません。

PDFも生成する場合は、次を実行します。Chromeが必要です（実行ファイルは `CHROME` で指定可能）。

```sh
python3 -B prototypes/chapters-1-2/build.py --pdf
```

- `output/pdf/all.pdf`: 第1〜5章の通読版。解答をすべて開き、本文の関連箇所に配置した補足も含めます。
- `output/pdf/slides.pdf`: 第1〜5章のスライド版。段階表示を1段階につき1ページにします。補足・先取りは含めません。

PDFを生成すると、試作の目次にダウンロードリンクが付きます。PDFは既存のリポジトリ方針に従ってGit管理外とし、生成処理をGitに保存します。
本文内の試作の節参照は通読版PDF内で移動できます。比較用の元原稿へのリンクとスライドの試作HTMLへのリンクは、この作業コピー内のHTMLを開きます。
印刷確認用HTMLはGit管理外の `tmp/pdfs/` に生成します。受講者配布用Leanファイルの生成は行いません。

## プレビュー

リポジトリ直下をHTTPサーバーで配信し、次を開きます。

```text
/prototypes/chapters-1-2/preview/index.html
```

通読版から、同じ章のスライドへ移れます。
試作した章どうしの節参照は試作内へ、未改稿の章や旧版の節への参照は既存の `/docs/` へリンクします。

第3章は「帰納型・依存する組・再帰・Eq・Nat.le」、第4章は「全射の合成・偶数の和・かつ・または・否定・証明検査」の構成です。
第5章には、第3章から移した `structure`・匿名構成子・依存するフィールド・部分型と `Fin` を置き、旧第5章の `class`・`instance`、記法、集合、名前空間へつないでいます。
練習は第1〜5章の通し番号です。短い確認問題を本文に、複数の内容を組み合わせる問題や発展問題を章末に配置しています。

## 補足と比較用の元原稿

採用した補足は `src/` の関連箇所に置き、本文と同じ Lean 検査を受けます。
補足・先取りは通読版には含み、講義スライドには標準で含めません。
元の補足を一括した付録や、そこに含まれる旧番号の練習は、試作本文に自動追加しません。

`supplements.py` は `originals/` から比較専用の `preview/reference/` を生成します。
コピー時点の原稿と解答はそのまま保存しています。

本文だけを確認する場合は `python3 -B prototypes/chapters-1-2/build.py --text-only` を使います。
この場合、スライドとPDFは更新されません。

## 比較

`originals/` と `src/` を比べると、今回の変更だけ確認できます。
問題の番号は試作内で振り直しており、元の原稿の同じ番号と内容が一致するとは限りません。
