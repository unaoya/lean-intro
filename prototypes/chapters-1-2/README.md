# 第1〜4章 改稿試作

元の原稿からコピーして編集した相談用の版です。

- `src/`: 試作の本文と解答。今後の修正はここで行います。
- `originals/`: コピーした時点の元原稿8ファイル。比較と、元の補足の保存に使います。
- `PLAN.md`: 相談で決まった方針、今回の選択、保留事項。
- `slides/`: 試作だけに適用するページ境界と表示段階。
- `preview/`: 通読版・スライド版HTML。生成物です。
- `preview/reference/`: 第3・4章の元原稿の通読版。補足の前後の定義も確認できます。
- `output/pdf/`: 試作の通読版・スライド版PDF（Git管理外）。
- `checks/`: Lean検査と表示確認の結果。
- `original-sha256.json`: 試作開始時の正本全Leanファイルのハッシュ。

## 再生成

リポジトリ直下から実行します。

```sh
python3 -B prototypes/chapters-1-2/build.py
```

改稿した本文・解答8ファイルをLeanで検査してから、通読版とスライド版を `preview/` に生成します。
Leanのコンパイル結果は試作内の `.build/` に置きます。
HTML生成器とスライド用CSS/JavaScriptは、既存の `dev/tools/` を読み込んで利用します。
元原稿・公開中の `docs/`・正本のスライド設定は変更しません。

PDFも生成する場合は、次を実行します。Chromeが必要です（実行ファイルは `CHROME` で指定可能）。

```sh
python3 -B prototypes/chapters-1-2/build.py --pdf
```

- `output/pdf/all.pdf`: 第1〜4章の通読版。解答をすべて開き、元の補足も含めます。
- `output/pdf/slides.pdf`: 第1〜4章のスライド版。段階表示を1段階につき1ページにします。補足・先取りは含めません。

PDFを生成すると、試作の目次にダウンロードリンクが付きます。PDFは既存のリポジトリ方針に従ってGit管理外とし、生成処理をGitに保存します。
本文内の試作の節参照は通読版PDF内で移動できます。補足の元原稿へのリンクとスライドの試作HTMLへのリンクは、この作業コピー内のHTMLを開きます。
印刷確認用HTMLはGit管理外の `tmp/pdfs/` に生成します。受講者配布用Leanファイルの生成は行いません。

## プレビュー

リポジトリ直下をHTTPサーバーで配信し、次を開きます。

```text
/prototypes/chapters-1-2/preview/index.html
```

通読版から、同じ章のスライドへ移れます。
章外への節参照は、既存の `/docs/` にある通読版へリンクします。

第3章は「帰納型・依存する組・再帰・Eq・Nat.le」、第4章は「全射の合成・かつ・または・否定・偶数の和」の構成です。
`structure`・匿名構成子・部分型の本文での説明は第5章へ回す方針で、第3・4章から外しました。第5章自体はまだ改稿していません。

## 元の補足

第3・4章の補足・先取りは9項目ずつ、通読版末尾の「元原稿から残した補足」に保存しています。
`supplements.py` が `originals/` のLean本文と解答から生成し、本文・コード・解答の文字列が変わっていないことを検査します。
講義のスライドには標準では含めません。

補足のコードは元原稿の定義を前提とする引用です。改稿した本文と混ぜて再コンパイルするものではなく、各項の「元の文脈で読む」で当時の定義を参照できます。
補足内の問題番号は元原稿のまま、試作本文の練習番号は第1〜4章で通し番号です。

## 比較

`originals/` と `src/` を比べると、今回の変更だけ確認できます。
問題の番号は試作内で振り直しており、元の原稿の同じ番号と内容が一致するとは限りません。
方針の相談は `PLAN.md` を基準に続けます。
