## 3.1 関数型 α → β — fun で作る・並置で使う

```lean
{{#include Ch3_DependentFunction.lean:arrow}}
```

**関数型 `α → β`** は、集合論では「直積 `α × β` の部分集合のうち各 `x` にちょうど一つの値が対応するもの（グラフ）」として*構成*される。だが型理論では関数型は**プリミティブ**（他の型から作らない原始概念）だ。

**項を作る（導入）**は `fun`（λ）。`fun n => n + 1` で関数そのものを書く。**項を使う（除去）**は**関数適用**——これは記法上「**並置**」。スペースで項が並んでいるものはすべて関数適用と読む（数学で `f(x)` と書くものを Lean ではただ `f x` と並べる）。

## 3.2 依存関数型 Π (x : α) → β x — 真のプリミティブ

```lean
{{#include Ch3_DependentFunction.lean:dependent}}
```

`α → β` は「行き先 `β` が引数に依存しない」特別な場合にすぎない。本当のプリミティブは**依存関数型 `(x : α) → β x`**——行き先の型 `β x` が引数 `x` に依存してよい関数（Π 型）。

`#check ((n : Nat) → Fin (n+1))` が依存関数型の例だ（行き先 `Fin (n+1)` が引数 `n` で変わる）。依存関数の項も同じ `fun` で作る。非依存版（`α → β`）は `β` が `x` に依存しない退化した場合として包摂される——2 つの関数型は実は 1 つのプリミティブの特別な場合だ。

## 3.3 命題の → と ∀ も依存関数 — Curry-Howard 対応の片翼

```lean
{{#include Ch3_DependentFunction.lean:prop_as_function}}
```

命題の `→` も同じ関数だ。`A → B` の証明は `fun (a : A) => …` で作り、適用 `f a` で使う——**型も命題も `→` は関数**で、導入＝`fun`・除去＝適用。

さらに `∀ x, P x` は依存関数型 `(x : α) → P x` そのもの（codomain が `Prop`）。「`→` は `∀` の非依存版」「`∀` は依存関数の codomain が `Prop` の場合」と一望できる。

- **¬ A** も `A → False`（`False` への関数）——依存関数の仲間
- これが型理論の**2原始の一本**。もう一本 **inductive type（帰納型）** は Ch4 で扱う
- ∧ ∨ ∃ ⊥ = は帰納型・→ ∀ ¬ は依存関数——論理はこの 2 つの原始で尽きる（Ch4 末で `#print` 確認）
