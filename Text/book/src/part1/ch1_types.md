# Ch2 型を作る — 型の構成と CH 対応

- 前章からの問い: Ch1 で「命題＝型・証明＝項」を見た。では型そのものはどう「作る」のか

## はじめに — 型とは何か・型の作り方のルール

- **「型とは何か」は問わない**: 「集合とは何か」と同じく原始概念で、定義しないのがよい。代わりに型が**どう振る舞うか**を見る
- `項 : 型`——コロンの**左に書くのが項・右に書くのが型**。Lean がするのは「**項の型をチェックする**」こと（型チェック）。これが**証明の検証**につながる（項=証明・型=命題＝Curry-Howard）
- **型チェック ≈ 数学の型推論**: `f : a → b` で `f x` と書けば「x は a の要素」と思いたい——数学で日常的にやっている推論
- ⚠ **タクティク**は「書かれた項を、証明の後から書き換える」補助的な機能（種明かしは第II部 Ch7）
- **型の作り方にはルールがある**: ZF が「どんな集合を作れるか」を公理で規定するように、型理論は「**どうやって新しい型を作るか**」を規定する。ZF で直積が他の公理から導かれるのと同様、型でも直積・直和は**より原始的なもの**——最も根本的な **帰納型（inductive）と依存関数（Π型）**——から作られる。本章はその基本構成を一望する（🪟 窓: ZF ↔ 型理論の対比・導入規則と除去規則 ↔ 自然演繹）

## 2.1 積 α × β — ペアを作る・取り出す

二つの型 `α`・`β` から、その**直積** `α × β`（ペアの型）が作れる。集合論の直積 `A × B` の型版だ。

```lean
{{#include Ch2_Types.lean:product}}
```

**項を作る（導入）**。正式には `Prod.mk` という関数を使う。`#check @Prod.mk` の結果 `{α β} → α → β → α × β` が示すとおり、これは「`α` の項と `β` の項を受け取って `α × β` の項を返す **2 引数の関数**」だ。だから `Prod.mk a b` でペアが作れる。

普段書く `⟨a, b⟩` は、この `Prod.mk a b` の**略記**である（anonymous constructor——Lean が型 `α × β` からどの構成子を使うかを推論し、`Prod.mk` を補う）。`⟨ ⟩` は積に固有の記号ではなく「型から構成子を推論して呼ぶ」汎用記法で、後で and・subtype・sigma でも同じ `⟨ ⟩` が現れる。

**項を使う（除去）**。正式には `Prod.fst`・`Prod.snd`。型はそれぞれ `α × β → α`・`α × β → β`、「ペアから第 1・第 2 成分を取り出す関数」だ。`p.fst`・`p.1` は `Prod.fst p` の、`p.snd`・`p.2` は `Prod.snd p` の**略記**（dot 記法）。

**命題との対応（Curry-Howard）**。命題の連言 `A ∧ B` も全く同じ機構でできている。正式な導入は `And.intro`（型 `a → b → a ∧ b`——`Prod.mk` と同じ形）、除去は `And.left`・`And.right`（`.1`/`.2`）。証明 `h : A ∧ B` から `⟨h.2, h.1⟩` で `B ∧ A` を作るのは、ペアの成分を入れ替えるのと**同じ操作**だ。これが「**積 ↔ ∧**」という対応の最初の例である。

## 2.2 和 α ⊕ β — どちらかを入れる・場合分けで取り出す

二つの型から**直和** `α ⊕ β` を作る。集合論の**直和（disjoint union）** `A ⊔ B` の型版で、`α` の項にも `β` の項にも「左から来た／右から来た」のタグを付けて 1 つの型に集める。タグがあるから、たとえ `α = β` でも由来を忘れない（だから *disjoint*）。

```lean
{{#include Ch2_Types.lean:sum}}
```

**項を作る（導入）**は `Sum.inl`・`Sum.inr` の二つ。型を見ると `Sum.inl : α → α ⊕ β`・`Sum.inr : β → α ⊕ β`——これは「`α` を左成分として `α ⊕ β` に包む**自然な射（包含写像）**」だ。集合論で `A` を `A ⊔ B` に埋め込む包含 `A ↪ A ⊔ B` に当たる。直和の項を作るには、必ずどちらかの射を通す。

**項を使う（除去）**は場合分け（`match`）で、どちらの射で作られたかを見て分岐する。これは集合論の「**直和の普遍性**」——`A ⊔ B` 上の関数は `A` 上の関数と `B` 上の関数の対でちょうど決まる——をそのまま写している。`sumToNat` は `Sum.inl n => …`・`Sum.inr b => …` の二枝で関数を定義している。

**命題との対応**。選言 `A ∨ B` も同じだ。正式な導入は `Or.inl`・`Or.inr`（型 `a → a ∨ b`——`Sum.inl` と同じ形）、除去は `Or.elim`（場合分け）。`h : A ∨ B` から `h.elim Or.inr Or.inl` で `B ∨ A` を作る（Ch1 の `or_swap`）のは、直和の左右を入れ替える操作と**同じ**。これが「**和 ↔ ∨**」の対応である。

## 2.3 Subtype `{x : α // p x}` — 値と「条件を満たす証明」を束ねる

ここから**依存**の世界に入る。`{x : α // p x}` は「述語 `p : α → Prop` を満たす `α` の項」だけを集めた型。集合論の**部分集合** `{x ∈ A | p(x)}` の型版だが、型理論では「`p` を満たす」という*証明*も項に同梱する。

```lean
{{#include Ch2_Types.lean:subtype}}
```

**導入**は `Subtype.mk`：値 `x` と「`p x` の証明」のペアを作る。`⟨3, by omega⟩` はその略記（`3` と「`3 < 5` の証明」）。**除去**は `.val`（値）と `.property`（証明）——部分集合の元から「値そのもの」と「条件を満たす事実」を取り出せる。

**命題との対応**。存在 `∃ x, p x` も「証人 `x` と `p x` の証明」のペアだ。違いは住む宇宙だけ：`∃ x, p x` は**証明（Prop）**で証人を計算的に取り出せない。`{x // p x}` は**データ（Type）**で `.val` で値を取り出せる。だから Subtype は「**∃ をデータに格上げした型**」と言える。第II部 Ch5 で添字に使う `Range n = {i : Nat // i < n}` はこの実例だ。

## 2.3b 依存和 `Σ x : α, β x` — Subtype の一般化（族の直和）

Subtype の第 2 成分は**証明** `p x : Prop` だった。これを一般の**型** `β x : Type` に変えると**依存和** `Σ x : α, β x` になる。集合論では「**族 `{β x}` の直和**」——各 `x` ごとの集合 `β x` を `x` でタグ付けして集めたもの（§2.2 の直和を、二つでなく `α` 個の族へ広げた版）。

```lean
{{#include Ch2_Types.lean:sigma}}
```

例の `Σ n : Nat, Fin (n+1)` は「`n` と、`Fin (n+1)`（0〜n の n+1 個）の項」のペアで、第 2 成分の*型*が第 1 成分 `n` で変わる。**導入**は `Sigma.mk`（`⟨2, 0⟩`）、**除去**は `.1`・`.2`（`.2` の型は `.1` に依存する）。

**Subtype との関係・気になる点**。`Subtype` は「依存和の第 2 成分が `Prop`（命題）である特別な場合」と見える。ここで一つ引っかかる：「*証明*（Prop の住人）も、型の族 `β x` のメンバーに選べてよいのか？」——答えは yes だ。Lean では **`Prop` は `Sort 0`・`Type` は `Sort (u+1)`** と、同じ `Sort` 階層に**地続き**に並んでいる。第 2 成分に証明（Prop）を選べば Subtype、一般の型（Type）を選べば本来の Σ。この「Prop と Type の地続き性」——なぜ命題の宇宙だけ特別なのか——は第II部 Ch4 の universe で正面から扱う。

```lean
{{#include Ch2_Types.lean:quotient}}
```

- ⚠ **本編 FTC では商は使わない**——型の構成を一望する（CH 対応の網羅）ための例。整数を商で作る面白さを見せる読み物的な節（初読では軽く流してよい）
- 整数 = `(Nat × Nat)/~`、`(a,b) ~ (c,d) ⟺ a+d = c+b`（直感: `(a,b)` は差 a−b・`(n,n)` はすべて 0 と同一視）
- 導入（「への」関数）: `Quotient.mk`（代表を入れる）／除去（「からの」関数）: `Quotient.lift`（well-defined を示して使う・**発展**へ）
- ※ 同値関係の反射/対称/推移は `omega`（第II部 Ch9 の自動化）に任せ、ここでは結果だけ借りる
- 0 の同一視: `(n,n)` はどれも `(0,0)` と同じ整数（差が 0）

## 2.6 まとめ — 型の構成手段の一覧（CH 対応）

型の構成（×・⊕・部分型・依存和・商・帰納型）と命題の構成（∧・∨・∃・帰納的命題）は**同じ機構**:

- 導入 = 項を作る = その型「への」関数（`⟨⟩`・`inl`/`inr`・構成子）
- 除去 = 項を使う = その型「からの」関数（`.1`/`.2`・`match`・パターンマッチ）

Curry-Howard 対応:「型 ↔ 命題・項 ↔ 証明」。

**2本柱の本格的な宣言は次章以降へ**。関数型・依存関数型（Π型）の導入/除去は **Ch3**、帰納型の再帰・recursor の全体像と論理結合子=帰納型の種明かしは **Ch4** でまとめて扱う。
