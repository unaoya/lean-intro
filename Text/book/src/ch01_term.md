# Ch1 最初の証明 — 命題=型・証明=項

<!-- 下書き（配置設計版）: 節立てと内容の配置メモのみ。本文未執筆 -->

- 前章からの問い: ゴール表示の中の `⊢` とは何か
- 到達点: 命題論理の証明を「データ」として手書きできる。**等式の証明を calc で繋げる**（Real 不要・タクティク不要・term mode のまま）
- 新しい Lean 機能: 命題=型・証明=項（term mode）・fun・⟨⟩・射影・**calc（等式の連鎖・term mode）**
- コード: C01_FirstProofs.lean

## 1.1 証明はデータである

- `example : 1 = 1 := rfl` から。「定理を述べる」と「証明を与える」が `def` と同じ形をしている
- 型を住人で説明する（Nat の住人は 0,1,2,…。`1 = 1` の住人は rfl）

## 1.2 かつ ∧ — ペア（導入規則と除去規則）

- 論理結合子はすべて**帰納型（非再帰）**。各々に**導入規則**（構成子＝作る）と**除去規則**（使う）がある——この対が以後ずっと縦糸（Ch4 で Nat の除去＝induction に繋がる）
- ∧ の導入 = And.intro・無名コンストラクタ ⟨,⟩／除去 = 射影 .1 / .2
- 演習: A ∧ B → B ∧ A（swap を項で書く）

## 1.3 ならば → — 関数

- 含意の証明は関数 `fun h => …`。modus ponens は関数適用
- 演習: (A → B) → (B → C) → A → C（合成）

## 1.4 または ∨ と否定 ¬

- ∨ の導入 = Or.inl / Or.inr（2 つの構成子）／除去 = `.elim`（場合分け）。**この `.elim` が ∨ の除去規則＝場合分け（cases）**——∨ は非再帰なので帰納法の仮定 (IH) は無い。`and_or_distrib` で実際に場合分けを使う
- 縦糸の予告: 「除去規則 = recursor」「型が再帰すると除去に IH が付いて induction になる」全体像は **Ch4**（Nat）。ここでは「∨ の除去 = cases」だけ握っておく
- ¬A は A → False（Bot への関数）。演習: A → ¬¬A

## 1.5 CH 対応表 — 導入規則と除去規則（縦糸の中心）

- **各論理結合子に導入規則（証明を作る）と除去規則（証明を使う）がある**。これを全結合子で揃えた表を提示（ロードマップ。∀∃ は Ch3・「正体」の裏取りは Ch4）:

| 命題 | 型（Lean） | 導入規則 | 除去規則 | 正体 |
|---|---|---|---|---|
| A → B | `A → B` | `fun`（λ） | 適用 `f a` | 依存関数（非依存 Π） |
| ∀ x, P x | `(x:α) → P x` | `fun`（λ） | 適用 `f a` | **依存関数（Π）**・Ch3 |
| ¬ A | `A → False` | `fun` | 適用 → False | 関数 → ⊥ |
| A ∧ B | `And` | `⟨_,_⟩` | `.1` `.2` | 帰納型（構成子 1） |
| A ∨ B | `Or` | `.inl` `.inr` | `.elim`（cases） | 帰納型（構成子 2） |
| ∃ x, P x | `Exists` | `⟨a, h⟩` | `.elim`（cases） | **帰納型（依存）**・Ch3 |
| ⊥ False | `False` | （無し） | `False.elim`（爆発） | 帰納型（構成子 0） |
| ⊤ True | `True` | `trivial` | （無し） | 帰納型（構成子 1・引数無） |
| a = b | `Eq` | `rfl` | `▸`（subst） | 帰納型（構成子 1） |

- **パンチライン（Ch4 で #print 確認）**: → ∀ ¬ は**依存関数（Π）**、∧ ∨ ∃ ⊥ ⊤ = は**帰納型**。つまり論理は **2 つの原始（Π＋帰納型）の導入/除去規則だけ**で書ける。→ と ∀ が同じ「関数」なのが要——codomain が引数に依存するかだけの違い
- 🪟 窓: BHK 解釈 — 構成主義の意味論（CH は BHK の型理論による実装。導入＝BHK の「証明とは何か」・除去＝その使い方）

## 1.6 等式の証明も項 — calc（ANCHOR `calc_warmup`・`nat_interchange`）

- 等式 `a = b` も命題＝型・その証明も項。複数の等式を 1 本ずつ繋ぐのが `calc`（`by` を使わない**term mode** のまま・各 `:= ` の右にその 1 行を正当化する項を置く）
- ウォームアップ `add_swap_left`（2 段）→ **`nat_interchange`**: `(a+b)+(c+d) = (a+c)+(b+d)` を `Nat.add_assoc`・`Nat.add_comm` だけで繋ぐ
- 素材は Nat だけ（Real 不要）。`congrArg (fun x => …)` で「等式を文脈に持ち上げる」のが calc の各段
- **演習**: 乗法版 `(a*b)*(c*d) = (a*c)*(b*d)` を同じ calc で（`namespace Solutions` に解答）
- 伏線: この式を Ch2 で「**任意の可換モノイド**」について 1 回証明し、`+` と `*` の両方に効かせる（具体→抽象）
- calc の深掘り（`≤`/`<` の混在連鎖・Trans インスタンス）は Ch7

## 引き

- 「`1 = 1` の 1 は Nat だった。`+` の式も 1 本ずつ繋げた。だが `×` でも同じ証明を繰り返すのか？——実数とは何か、そして式の繰り返しをどう束ねるか。それは『構造』だ（Ch2）」
