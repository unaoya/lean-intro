# Ch2 型を作る — 型の構成と CH 対応

<!-- 下書き（配置設計版）: 節立てと内容の配置メモ。本文未執筆。構成v7 で新設した章 -->

- 前章からの問い: Ch1 で「命題＝型・証明＝項」を見た。では型そのものはどう「作る」のか
- 到達点: 基本的な型の構成（積・和・関数・帰納型・商）を一望し、各構成の **「導入（項を作る＝その型への関数）」と「除去（項を使う＝その型からの関数）」** を、命題の論理結合子（∧・∨・→）と対比する＝**Curry-Howard 対応の骨格**
- 新しい Lean 機能: `Prod ×`・`Sum ⊕`・関数型 `→`・`inductive`（有限集合）・`Quotient`（商）／導入 `⟨⟩`・`inl`/`inr`・`fun`・構成子／除去 `.1`/`.2`・`match`・適用・パターンマッチ
- コード: C02_Types.lean（product・sum・arrow・finite・quotient）
- ★ **縦糸**: 「導入＝その型へ・除去＝その型から」が型と命題で**同じ機構**。後で `intro`/`cases`/`⟨⟩` が型と命題の両方で同じタクティク（Ch5 で recursor として種明かし・Ch7 で実戦）
- **役割分担**: この章は「型を**作る**」（CH 対応の一望）。型に**構造を載せる**のは Ch3、帰納型の再帰・recursor の本格（Nat.rec→Summation）は Ch5、商の演算 well-defined（Quotient.lift）は発展

## 2.1 積 α × β ↔ ∧（ANCHOR `product`）

- 導入（項を作る＝α×β「への」関数）: `⟨a, b⟩`／除去（使う＝α×β「からの」関数）: `.1`/`.2`
- 対比: 命題の ∧ も同じ機構（`A ∧ B` を `⟨h1, h2⟩` で作り `.1`/`.2` で使う）——Ch1 の `⟨h.2, h.1⟩` がまさにこれ

## 2.2 和 α ⊕ β ↔ ∨（ANCHOR `sum`）

- 導入（α⊕β「への」関数）: `Sum.inl`/`Sum.inr`／除去（「からの」関数）: 場合分け `match`
- 対比: 命題の ∨ も同じ（`Or.inl`/`inr` で導入・`.elim` で除去）——Ch1 の `or_swap` がこれ

## 2.3 関数 α → β ↔ →（ANCHOR `arrow`）

- 導入（α→β「への」関数＝関数そのもの）: `fun`／除去（使う）: 適用
- 対比: 命題の → も同じ関数（`A → B` の証明は `fun` で作り適用で使う）——**型も命題も → は関数**

## 2.4 帰納型で型を作る — 有限集合 Three とその上の関数（ANCHOR `finite`）

- 導入（Three「への」関数＝構成子）: `inductive Three | a | b | c`（3 つの住人を並べた有限集合 ≅ {0,1,2}）
- 除去（Three「からの」関数）: パターンマッチで各構成子を捌く（`label : Three → Nat`＝有限集合上の自然数値関数）
- Three「への」関数（別の型から）も構成子で（`pick : Bool → Three`）
- 🪟 窓: 「型を作る→そこから/への関数」が論理結合子の導入/除去と同じ——CH 対応がここで具体に見える

## 2.5 商 Quotient — 同値関係で割る（整数 (Nat×Nat)/~ の予告）（ANCHOR `quotient`）

- 整数 = `(Nat × Nat)/~`、`(a,b) ~ (c,d) ⟺ a+d = c+b`（直感: `(a,b)` は差 a−b・`(n,n)` はすべて 0 と同一視）
- 導入（「への」関数）: `Quotient.mk`（代表を入れる）／除去（「からの」関数）: `Quotient.lift`（well-defined を示して使う・**発展**へ）
- ※ 同値関係の反射/対称/推移は `omega`（Ch9 の自動化）に任せ、ここでは結果だけ借りる
- 0 の同一視: `(n,n)` はどれも `(0,0)` と同じ整数（差が 0）

## 2.6 まとめ — 導入＝そこへ・除去＝そこから（CH 対応）

- 型の構成（×・⊕・→・帰納型）と命題の構成（∧・∨・→・帰納的命題）は**同じ機構**:
  - 導入 = 項を作る = その型「への」関数（`⟨⟩`・`inl`/`inr`・`fun`・構成子）
  - 除去 = 項を使う = その型「からの」関数（`.1`/`.2`・`match`・適用・パターンマッチ）
- Curry-Howard 対応:「型 ↔ 命題・項 ↔ 証明」。だから後で `intro`/`cases`/`⟨⟩` が型と命題の両方で同じタクティクとして効く（Ch5 で recursor として種明かし・Ch7 で実戦）

## 演習

- `Nat × Bool` の項を作る/分解する・`Nat ⊕ Bool` の場合分け・`Three` 上の別の関数（`Three → Bool` 等）
- 商の同一視を手で確認（`(2,5) ~ (0,3)` か？＝差が −2 で一致）
