## 14.1 なぜ id は直接いけるのか

- 中点タグなら RS が**厳密に** (b²−a²)/2 になる（中点和＝望遠鏡和。telescope_sum の回収）
- 一般のタグは中点から各小区間 ±len/2 しかずれない → 合計 ±(δ/2)(b−a)

## 14.3 isintegral_id 精読

- 中点和の望遠鏡化 → 差の両側評価 → δ := ε/(b−a) の配分。退化区間 [a,a] は degenerate_sum（全分点が潰れる小教材）

## 14.4 監査: sup なし

- `#print axioms isintegral_id` に choice はあるが **sup がない**——「定義から直接」の可積分性は完備性不要。**どこで sup が要るのか**（Ch15 と発展部）の対照実験

## 14.5 integral_id — 橋の 2 回目

- 値関数の等式へ（Ch13 の再演）。**Ch8 との接続**: n 等分の RS=(n+1)/(2n) → 1/2 と ∫₀¹x = 1/2 が integral_unique で同じものになる——貫通具体例が部をまたいで閉じる
