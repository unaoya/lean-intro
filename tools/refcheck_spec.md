# 固定ラベルによる節参照と番号同期（refcheck）

## 目的

節の追加・削除・移動に伴う参照番号の手修正をなくす。
**参照先の正は固定ラベルであり、節番号は並び順から生成する表示値**とする。
`.lean` は一次教材なので、同期後のソースにも「7節」のような読める番号を残す。
スクリプトの機能と、既存教材へのラベル付け・内容訂正は別の変更として扱う。

## 見出しと参照の書式

```lean
/-! ## 3. 関数 {#sec-Intro1.functions}

この書き方は [4節](#sec-Intro1.dependent-functions) と組み合わせて使える。
[`04_Exists.lean` 8節](#sec-CH.nat-proofs) も参照。
-/
```

- ラベルは全章を通して一意な `[A-Za-z][A-Za-z0-9_.-]*`。
  先頭の `Intro1.` 等は名前の衝突を避ける慣習で、参照先ファイルは実際の見出し位置から決める。
  章を分割してもラベルは保つため、現在の `01_TypesAndTerms`・`03_InductiveTypes` にも `Intro1.` が使われている。
- 見出しを移動・改題してもラベルは変えない。
- 新しい見出しは `## 関数 {#sec-Intro1.functions}` のように番号なしで書ける。
- 節を統合する場合、旧見出しを `### 整理 {#sec-旧ラベル}` に下げても固定ラベルを保てる。
  小見出し自体には番号を付けず、参照の表示には所属する `##` の節番号を使う。
  解答の `SOL` とスライドのアンカーも旧ラベルのまま使える。
- 新しい参照は `[節](#sec-Intro1.functions)` と書ける。番号やファイル名を手入力する必要はない。
- 同期後は同じ章なら `[3節](#sec-Intro1.functions)`、別章なら
  ``[`01_TypesAndTerms.lean` 3節](#sec-Intro1.functions)`` になる。
- 既存の明示的なファイル名・「の」・番号と「節」の間の空白は保持する。
  ファイル名は実際の参照先に同期する。解答内の同章参照は対応する本文を指す。
- 範囲の両端も固定ラベルにする。例:
  `[1](#sec-CH.products)〜[3節](#sec-CH.empty-types)`。
  各端点は独立した参照であり、範囲の数学的・叙述的な意味までは検証しない。
- リンクの表示部には `節`、`N節`、`N`、またはその前にバッククォート付きファイル名を置ける。
  任意の説明文をリンク内に混ぜない。説明はリンクの後に書く。
- 参照の途中に1回の改行を含めてもよい。原本の行番号で診断する。

## 番号付け

- `lean2html.CHAPTERS` の章ごとに、`parse()` が返す `prose` の行頭 `## ` 見出しを走査する。
  固定ラベル付き見出しだけを出現順に採番し、古い表示番号は判断に使わない。
- 開始番号は既定で1。02_Forall は0（`refs.SECTION_STARTS`）。旧版の生成時は旧 CH を0に設定する。
- 固定ラベル付きの `###` は、直前の固定ラベル付き `##` に属する。
  次の節の番号は増やさない。所属する節がない小見出しはエラーにする。
- 番号付き見出しのラベル忘れはエラー。無番号・ラベルなしの序文や付録は採番しない。
- 見出しのラベルは `prose` にだけ定義できる。docstring やコード中の見出しらしい文字列は対象外。
- 見出しと同じ節内の `### 補足` を記録する。無番号の `## ` 見出しで所属を切り替える。

## 検査・更新

対象は `CHAPTERS` と `SOL_FILES`、および存在する `07_ExercisesSol.lean`。
標準ライブラリだけを使い、セグメント分割は `lean2html.parse()` を再利用する。

```bash
python3 tools/check_refs.py        # 読み取り専用。未同期・不正な参照は exit 1
python3 tools/check_refs.py --fix  # 見出し・参照の表示番号を同期
python3 tools/lean2html.py --no-pdf # 同期と検査を行ってから HTML 生成
```

- 不明なラベル、重複ラベル、不正な予約構文、ラベルなしの番号参照はエラー。
  日本語直後の「これが7節」、空白入りの「11 節」も検出し、黙って見逃さない。
- 診断は `ファイル名:行番号: 対象 → 理由`。構造上のエラーがあれば全ファイルの同期を止める。
  検査後に原本が変わった場合も同期を止める。
- 更新するのは固定ラベル付き見出しの番号と、参照リンクの表示部だけ。
  不明なラベルを推測して別のラベルへ変更しない。
- 参照直後の `（キーワード）` は、バッククォートを除いた節題の部分文字列であることを検査する。
  `の補足` が続くなら、参照先に補足見出しがあることも検査する。
- プローズ、docstring、コードコメントに同じ参照書式を使う。
  生の番号参照の検出は全テキストを対象とする。例外の行は `refcheck-ignore` を同じ行に置くか、
  直前の独立行に `-- refcheck: ignore-next-line` を置く。
  これはラベルなし参照の検出だけを抑止し、明示的な固定ラベル参照の不正は抑止しない。
- 「前節」「次節」「付録」等の無番号参照、07_Exercises の「Part N」は自動更新の対象外。
- 未同期の番号は `--fix` または HTML 生成時に更新する。
  「現行教材の全番号が同期済み」は移行後の確認条件であり、スクリプト自体の検証とは分ける。

## 解答の対応付け

`/-! SOL Intro1.functions:1 -/` のように、固定節ラベルと節内の問題番号を使う。
節番号は持たない。節を移動しても SOL マーカーを修正する必要はない。

同じ節に複数の練習ブロックがあり、問題番号が1から再開することは許容する。
対応は**節ごとの出現順**で検査する。欠落・余分な解答・問題番号の不一致は生成エラー。
節内の練習ブロック自体を入れ替える場合は、解答側も同じ順序にする必要がある。
章をまたいで節を移す場合は、解答チャンクも対応する解答ファイルへ移す。

## HTML

- 見出しの ID は `sec-固定ラベル`。番号変更後もリンク先は変わらない。
- 通常のプローズ・docstring では参照をリンク化する。同章は `#sec-...`、別章は
  `ch2.html#sec-...` のようなリンク。折りたたみ解答も本文の章を基準にする。
- コード・引用コードはリンク化せず、参照の表示部だけを表示する。
  見出しのラベル注記も HTML の本文には表示しない。
- 結合した印刷用 HTML では全参照を文書内の固定ラベルへ向ける。

## 受け入れ条件

1. 番号なしの新規見出し・参照に番号が入る。再実行しても差分が出ない。
2. 節の挿入・入れ替え後、別ファイル・解答・日本語直後・改行をまたぐ参照を一括更新できる。
3. 不明・重複ラベル、未ラベルの番号参照はファイル名と行番号付きで失敗し、HTML を生成しない。
4. 節の入れ替え後も正しい解答が挿入される。既存の解答対応検査は残る。
5. HTML の参照先 ID が存在し、コード・引用・表示テキストに意図しない変化がない。
6. 教材移行後に `lake build` とスクリプトの検査が通る。
