はじめての Lean

型と命題 I — ならばと全称量化

この章では、その命題の証明を与えられたか、証明を書けたかという視点で数学を読む。命題の真偽を先に判定することや、同じ命題の証明どうしの文面を比べることから、いったん視点を移そう。注目するのは、その主張を支える保証を、実際に与えられたかどうかである。

ここでいう保証は、その命題の証明書だと思えばよい。証明がまだ書けていないということと、その命題が偽であるということは区別する。

保証を受け取って、保証を作る

ある前提のもとで結論が成り立つ、という定理を考えよう。これは「前提が正しいという保証を与えてくれたら、結論が正しいという保証を作ります」と言っている、と読める。

この説明のために前提を $P$、結論を $Q$ と呼ぶ。「$P$ ならば $Q$」を保証するには、$P$ の証明書を受け取り、$Q$ の証明書を返す関数を書けばよい。ここで受け取るものと返すものは、真・偽という値ではなく、それぞれの命題の証明書である。

命題をその証明書の型と思えば、この関数の型は $P\to Q$ になる。仮定のもとで結論を示す、という証明の形を、入力から出力を作る関数の形として捉えている。

対象ごとに、その対象についての保証を与える

「どんな $x$ に対しても $P(x)$ が成り立つ」を保証する場合はどうだろうか。必要なのは、どの $x$ を渡されても、その $x$ についての命題 $P(x)$ の証明書を返すことである。一つの関数で、すべての対象に対する保証を一斉に与える。

返す証明書の型は $P(x)$ であり、受け取った $x$ に応じて変わる。だから、その保証を与えるものは依存関数だと考えられる。前の章で、$n$ に対して Fin (n + 1) の項を返したのと同じ形で、今度は対象ごとの証明を返す。

各 $x\in A$ に命題 $P(x)$ を割り当てるものを述語という。命題を型と思えば、述語は $A$ を添字とする型の族 $(P(x))_{x\in A}$ である。全称命題の証明は、この族の各型 $P(x)$ の項を返す依存関数、すなわち依存積 $\prod_{x\in A}P(x)$ の項なのである。

人間が納得することと、機械が検査すること

人間が理解したいことは、この読み替えが、数学でしている証明の操作を表しているということである。「ならば」を証明する代わりに保証から保証を作る関数を、全称命題を証明する代わりに対象から保証を作る依存関数を書く。その関数を作れたことで、元の数学の主張を証明したと納得できるかを考えたい。

機械が確かめることは、渡された項が、指定された型を持つかどうかである。この読み替えのもとで書いた証明の項を型検査し、要求された結論の証明になっているかを確かめる。数学の主張をどう表したかを読むことと、できた項の型を検査することの、両方が必要になる。

単射の合成、左キャンセル、単調写像の合成、左逆の四つを通して、この対応を見ていこう。

1. 単射の合成 — 対象と仮定を受け取る

写像 $f : A\to B$ と $g : B\to C$ がともに単射なら、合成 $g\circ f : A\to C$ も単射である。まず、ふつうの数学の証明を書いてみよう。

数学の証明を読む

証明。 $x,y\in A$ を任意に取り、$g(f(x))=g(f(y))$ と仮定する。$g$ は単射だから $f(x)=f(y)$ である。さらに $f$ は単射だから $x=y$ となる。したがって、$g\circ f$ は単射である。∎

学生のレポートを採点するつもりで、この証明を読んでみよう。各行で述べたことは、どの仮定から言えるだろうか。最後の結論に必要な対象と仮定が、最初にきちんと取られているだろうか。証明の書き方を「対象を取り、仮定を明示し、それを使って結論を得る」という一定の形にそろえると、仮定の取り忘れや推論の抜けを確認しやすくなる。

対象と仮定を受け取り、保証に名前を付ける

まず、$f$ の単射性の保証を hf、$g$ の単射性の保証を hg と名付ける。次に二つの対象 $x,y\in A$ を任意に取り、等式 $g(f(x))=g(f(y))$ の保証を h と名付ける。 Lean の書き方では、次のようになる。

h : g (f x) = g (f y)

これは等式を表す文字列ではなく、その等式を保証する証明書に h という名前を付けている。一般に h : x = y と書けば、x = y であるという保証を h と名付けたことになる。対象に名前を付ける x : A と同じ配置で、型の場所に命題を書いている。

この名前を使って証明を読み直そう。hg に対象 $f(x),f(y)$ と保証 h を渡すと、$f(x)=f(y)$ の保証が得られる。これを、対象 $x,y$ とともに hf に渡すと、$x=y$ の保証が得られる。「これらを与えられたら、これを作る」という操作に分けると、仮定を使う各行が関数適用として、証明全体が対象と保証を受け取る関数として見えてくる。

命題を型、証明をその型の項として読む

Lean では命題そのものを型とし、その型の項を証明として扱う。自然数の型とその項の関係と、命題とその証明の関係を並べてみよう。 1 + 1 = 2 の証明を h と名付けたとする。

Nat : Type
2 : Nat

(1 + 1 = 2) : Prop
h : 1 + 1 = 2

Prop は命題たちの型であり、証明 h の型は、その証明が保証する命題 1 + 1 = 2 である。

証明に名前を付けるときも def 名前 : 型 := 項 を使う。指定する型が証明したい命題で、右辺の項がその証明書になる。

✏ 練習

  1. #check 3 = 5 と #check 5 = 5 の表示を予想せよ。 #check の結果から、命題が真かどうかを判断できるか。

解答 28

#check 3 = 5
3 = 5 : Prop
#check 5 = 5
5 = 5 : Prop

どちらも命題なので型は Prop。#check は、命題を表す項の型を調べている。真偽や証明の有無を調べているわけではない。

単射性を、全称量化と「ならば」で書く

「どの x、y についても」は ∀ x y と書く。∀ は \forall で入力できる。この ∀ は依存関数型の記法であり、∀ x : A, B x は (x : A) → B x と同じ型を表す。また、二つの命題の間の → を「ならば」と読む。$f$ の単射性を表す命題は、次のようになる。

∀ x y : A, f x = f y → x = y

関数適用は等号より強く結び付き、f x = f y は (f x) = (f y) と読む。

その証明を hf と名付ける。$g$ の単射性の証明は hg とし、それぞれの型を、数学で使った条件のまま書く。

hf : ∀ x y : A, f x = f y → x = y
hg : ∀ u v : B, g u = g v → u = v

示したい結論は、合成の単射性である。

∀ x y : A, g (f x) = g (f y) → x = y

全称量化も「ならば」も関数として扱っている

hf の型は、依存関数型の記法でも書ける。

hf : (x : A) → (y : A) → (f x = f y → x = y)

最初の二つの引数は対象である。その値 x、y によって、残りの型に現れる等式も変わる。これが、全称量化の証明が依存関数であるという意味である。

対象を二つ渡した後の hf x y は、f x = f y の証明を受け取り、x = y の証明を返す。ここでは入力も出力も証明だが、関数を適用する規則は前の章と変わらない。

このとき、命題である関数型と、その型の項である関数を区別しよう。

(f x = f y → x = y) : Prop
hf x y : f x = f y → x = y

上の行は「ならば」で作った命題であり、下の行の hf x y が、その命題の証明となる関数である。

hf は、引数を一度に受け取るのではなく、順に受け取る関数として読める。

hf : (x : A) → (y : A) → (f x = f y → x = y)
hf x : (y : A) → (f x = f y → x = y)
hf x y : f x = f y → x = y

前章のカリー化と同じく、引数を一つ渡すたびに残りの関数が得られる。依存関数なので、そのたびに残りの型にも渡した対象が代入される。

証明を一つの関数の項にする

結論を外側から読むと、まず x : A と y : A、次に h : g (f x) = g (f y) を受け取り、x = y の証明を返せばよい。この「受け取る」を、fun x y h => と書く。

では、本体をどう作るか。欲しい結論 x = y から考えると、 hf x y は f x = f y の証明を受け取って、その結論の証明を返してくれる。そこで、まず f x = f y の証明を作ればよい。

hf x y : f x = f y → x = y

このために hg に渡す対象は、x、y ではなく、B の項である f x、f y である。 hg (f x) (f y) が要求する等式は、ちょうど手元の h が保証している。

hg (f x) (f y) : g (f x) = g (f y) → f x = f y

したがって hg (f x) (f y) h を作って hf x y に渡すと、本体が完成する。

証明の項は、仮定や既に与えられた定義・補題の名前を参照して組み立てられる。参照先の内容をすべて項の中に書き込む必要はなく、Lean はそれらの宣言も使って型を検査する。

def comp_injective (A B C : Type) (f : A → B) (g : B → C)
    (hf : ∀ x y : A, f x = f y → x = y)
    (hg : ∀ u v : B, g u = g v → u = v) :
    ∀ x y : A, g (f x) = g (f y) → x = y :=
  fun x y h => hf x y (hg (f x) (f y) h)

Lean は、この def の宣言を受理するときに証明の型検査を行う。後から #check comp_injective と書いたときには、既に検査された定義の型を確認している。

機械が行う型検査を追う

ここまでは結論からさかのぼって証明を組み立てた。今度は完成した項を、内側から型を求めて検査し直そう。右辺全体に期待される型は、結論に書いた次の型である。

(x : A) → (y : A) → (g (f x) = g (f y) → x = y)

右辺が fun x y h => … なので、機械は x : A、y : A、 h : g (f x) = g (f y) を使えるものとして、本体を検査する。本体に要求される型は、最後の結論 x = y である。

まず、内側の hg (f x) (f y) の型を求める。 hg の二つの対象に f x と f y を代入すると、次の型になる。

hg (f x) (f y) : g (f x) = g (f y) → f x = f y

この関数が要求する入力型は g (f x) = g (f y) であり、手元の h の型と一致する。したがって、h を渡した結果は次の型になる。

hg (f x) (f y) h : f x = f y

次に外側を見る。hf に x と y を渡すと、次の型になる。

hf x y : f x = f y → x = y

この入力型 f x = f y は、いま内側で得た証明の型と一致する。よって、その証明を渡した本体全体の型が分かる。

hf x y (hg (f x) (f y) h) : x = y

本体の型が、要求されていた結論の型と一致した。これで、x、y、h を受け取ってその本体を返す fun x y h => … 全体が、指定された全称量化と「ならば」の型を持つと確かめられる。

ここで機械がしているのは、宣言された型への引数の代入と、適用の入力型・出力型の照合である。「$g$ の単射性を使おう」という証明の発想をもう一度探すのではなく、 書かれた証明の各適用が型に合っているかを確かめている。

長い項を読むときは、括弧や型注釈を明示し、途中の結果の型を確かめるとよい。この例なら、内側を (hg (f x) (f y) h : f x = f y) と注釈できる。必要なら小さな定義に分けて名前を付ける。

証明を書けるかどうかに注目する

Lean では、同じ命題の証明どうしは、書き方が違っても同じ項として扱われる。証明が存在する場合、その命題に対応する型の項は、この意味で一つとみなせる。「ならば」や全称命題の証明である関数も、命題に対応する型の項なので、この扱いを受ける。このため、ここでは要求された型の関数を書けるかどうか、すなわち、その命題の証明を与えられるかに注目する。

示すときは、要求される引数を fun で受け取る。使うときは、対象や証明を適用で渡す。 全称量化と「ならば」が重なった証明も、この二つの操作で読める。

✏ 練習

  1. 写像 $f:\mathbb{N}\to\mathbb{N}$ が単調であるとは、任意の $x,y$ について、$x\le y$ ならば $f(x)\le f(y)$ となることである。$f,g$ が単調なら $g\circ f$ も単調であることを、comp_monotone という名前で証明せよ。単調性の仮定と結論の型を書き、fun と仮定の適用だけで証明の項を作ること。 ≤ は \le で入力する。不等式はいつもの意味で読み、その定義は帰納型のところで扱う。

解答 29

def comp_monotone (f g : Nat → Nat)
    (hf : ∀ x y : Nat, x ≤ y → f x ≤ f y)
    (hg : ∀ u v : Nat, u ≤ v → g u ≤ g v) :
    ∀ x y : Nat, x ≤ y → g (f x) ≤ g (f y) :=
  fun x y h => hg (f x) (f y) (hf x y h)

x、y と h : x ≤ y を受け取り、hf x y h : f x ≤ f y を作る。これを hg (f x) (f y) に渡せばよい。単射の合成とは逆に、もとの不等式から像の不等式へ進む。

2. 左キャンセル — 関数を引数として受け取る

単射 $f : A \to B$ と、二つの写像 $u,v : X \to A$ を考える。任意の $t \in X$ に対して $f(u(t)) = f(v(t))$ が成り立つとする。このとき、任意の $t \in X$ に対して $u(t)=v(t)$ が成り立つ。

各点で単射性を使う

証明。 $t\in X$ を任意に取る。仮定から $f(u(t))=f(v(t))$ であり、$f$ は単射だから $u(t)=v(t)$ となる。∎

仮定と結論はどちらも「すべての $t$ について」という形である。対象 t を受け取り、その点での等式の保証に単射性を適用すればよい。まず、仮定と結論を論理式として書く。

(∀ x y : A, f x = f y → x = y) →
  (∀ t : X, f (u t) = f (v t)) → ∀ t : X, u t = v t

二つの仮定の保証を hf、h と名付けると、使える項の型は次のようになる。

hf : ∀ x y : A, f x = f y → x = y
h : ∀ t : X, f (u t) = f (v t)
h t : f (u t) = f (v t)
hf (u t) (v t) : f (u t) = f (v t) → u t = v t

h t を最後の関数に渡せば、結論に必要な u t = v t の証明が得られる。

def cancel_pointwise (X A B : Type) (f : A → B)
    (hf : ∀ x y : A, f x = f y → x = y)
    (u v : X → A) (h : ∀ t : X, f (u t) = f (v t)) :
    ∀ t : X, u t = v t :=
  fun t => hf (u t) (v t) (h t)

h t は、対象 t に対する等式 f (u t) = f (v t) の証明である。これを hf (u t) (v t) に渡して、u t = v t の証明を得る。関数 u と v も引数になったが、証明の操作は先ほどと同じ適用である。

✏ 練習

  1. 単射 $f : A\to B$ と $u,v : X\to A$、 h : ∀ t : X, f (u t) = f (v t) を受け取ったとする。 ∀ t : X, u t = v t の証明を書け。 h 全体を単射性に渡すのではなく、どの項を渡せばよいか説明せよ。

解答 30

def cancel_pointwise_again (X A B : Type)
    (f : A → B)
    (hf : ∀ x y : A, f x = f y → x = y)
    (u v : X → A) (h : ∀ t : X, f (u t) = f (v t)) :
    ∀ t : X, u t = v t :=
  fun t => hf (u t) (v t) (h t)

h は全称命題の証明なので、まず対象 t を渡す。得られた h t : f (u t) = f (v t) が、hf (u t) (v t) の要求する入力である。各点で u t = v t の証明を作り、fun t => … で全体の証明にする。

3. Eq と rfl — 等式の保証を作る

ここまでは、仮定された等式の保証を使ってきた。次に、等式そのものと、その基本の証明をもう少し見ておこう。

等式を表す Eq

a = b は Eq a b という項の記法である。例えば自然数については、Eq は二つの自然数を受け取って命題を返す関数として使える。

#check Eq
Eq.{u_1} {α : Sort u_1} : α → α → Prop

共通の型 α を受け取り、その型の二つの項から命題を作る。 α := Nat と指定したときの型も確かめよう。

#check (Eq : Nat → Nat → Prop)
Eq : Nat → Nat → Prop

Eq 2 2 は 2 = 2 という命題、Eq 2 3 は 2 = 3 という命題である。同じ型の項どうしの等式を扱うので、Eq はその共通の型も暗黙引数として受け取る。上の注釈では、それが Nat と決まっている。

命題 Eq a b 自体と、その保証を区別しよう。 h : Eq a b、つまり h : a = b と書いたとき、h が等式の証明である。

自分自身との等式を保証する Eq.refl

等式の基本の証明を作るのが Eq.refl である。項 a を渡すと、a = a の証明を返す。

#check Eq.refl
Eq.refl.{u_1} {α : Sort u_1} (a : α) : a = a

型 α は暗黙引数、対象 a は明示引数である。

#check Eq.refl 2
Eq.refl 2 : 2 = 2

Eq.refl は等式の証明を作るコンストラクターである。その定義を帰納型として読む方法は後で学ぶが、今は、対象を渡せばその対象自身との等式の証明が得られる、と読めばよい。

rfl は、対象を暗黙引数にしたもの

Eq.refl a は対象 a を明示して a = a の証明を作る。 rfl は、この対象を暗黙引数にしたものである。Lean では、次のように def で定義されている。

def rfl {α : Sort u} {a : α} : a = a := Eq.refl a

ここで注目したいのは {a : α}。対象 a は、証明を置く場所で期待される型から補われる。 rfl 自体も普通の項であり、第1章で学んだ暗黙引数の実例になっている。

暗黙引数まで型に残して表示するため、@rfl を調べよう。

#check @rfl
@rfl : ∀ {α : Sort u_1} {a : α}, a = a

Eq.refl の (a : α) に対して、こちらは {a : α} である。対象を明示するなら @rfl Nat 2 と書ける。

計算して一致するときは rfl

rfl を使うと、期待される等式の型に合わせて対象が補われる。両辺が定義から計算して一致するときに使える。

def one_add_one : 1 + 1 = 2 := rfl

#check one_add_one
one_add_one : 1 + 1 = 2

左辺 1 + 1 は計算すると 2 になる。そのため、例えば Eq.refl 2 : 2 = 2 も、ここで要求された型 1 + 1 = 2 の項として使える。

def one_add_one_explicit : 1 + 1 = 2 := Eq.refl 2

計算して一致するかどうかは、Eq.refl を直接使った場合にも、型の照合で調べられる。 rfl だけに特別な計算能力があるわけではない。違いは、対象を明示するか、暗黙に補ってもらうかである。

✏ 練習

  1. def two_add_three : 2 + 3 = 5 := … の右辺を rfl で埋めよ。 rfl が使える理由を説明せよ。

解答 31

def two_add_three : 2 + 3 = 5 := rfl

左辺を計算すると 5 になり、右辺と一致するので rfl が使える。

  1. def oops : 2 + 2 = 5 := rfl は受理されるか。受理されないなら、どの二つの項が計算しても一致しないのかを説明せよ。

解答 32

受理されない。2 + 2 を計算した 4 と、右辺の 5 が一致しない。エラーには次の説明が現れる。

error: Not a definitional equality: the left-hand side
  2 + 2
is not definitionally equal to the right-hand side
  5

一般に、rfl が使えないだけで命題が偽だとは判断できない。ここで失敗したのは、計算して両辺を一致させるという確かめ方である。

対象ごとの等式を保証する

対象を受け取って、その対象自身との等式の証明を返すこともできる。 n を受け取るたびに、返す証明の型が n = n に決まる。

def all_refl : ∀ n : Nat, n = n :=
  fun n => (rfl : n = n)

#check all_refl
all_refl (n : Nat) : n = n

依存関数型の形では、次のように読める。

all_refl : (n : Nat) → n = n

入力 n によって返す証明の型が変わる。 ∀ n : Nat, n = n の量化部分が、引数 (n : Nat) として左側に表示されている。 Infoview でもこのような binder 形式が使われる。∀ の記号が見えなくても、「任意の n : Nat について n = n」という型は変わっていない。

#check all_refl 7
all_refl 7 : 7 = 7

これも全称量化の証明を依存関数として作り、対象を渡して使う例である。次は、このような等式の保証を逆向きに使ったり、二つつないだりする道具を使おう。

✏ 練習

  1. all_refl 12 の型を予想せよ。さらに fun n : Nat => all_refl (n + 1) の型を答えよ。

解答 33

#check all_refl 12
all_refl 12 : 12 = 12
#check fun n : Nat => all_refl (n + 1)
fun n ↦ all_refl (n + 1) : ∀ (n : Nat), n + 1 = n + 1

all_refl に n + 1 を渡すので、返される証明の型にも n + 1 が入る。全体は n を受け取って、その等式の証明を返す依存関数である。

Eq.symm — 等式の向きを逆にする

#check Eq.symm
Eq.symm.{u} {α : Sort u} {a b : α} (h : a = b) : b = a

h : a = b があるとき、Eq.symm h は b = a の証明になる。等式の証明を受け取り、逆向きの等式の証明を返す関数である。一般に、a = b の証明をそのまま b = a の証明として渡せるわけではない。等式の向きも型に含まれるので、逆向きの証明が必要なときは Eq.symm を使う。

h : a = b
Eq.symm h : b = a

対象 a と b は暗黙引数であり、渡した h の型から補われる。ここでも、第1章で見た暗黙引数の仕組みが使われている。

Eq.trans — 二つの等式をつなぐ

#check Eq.trans
Eq.trans.{u} {α : Sort u} {a b c : α} (h₁ : a = b) (h₂ : b = c) : a = c

h₁ : a = b と h₂ : b = c があるとき、Eq.trans h₁ h₂ は a = c の証明になる。一つ目の右辺と二つ目の左辺が一致することが、二つの証明を渡すための条件である。

h₁ : a = b
h₂ : b = c
Eq.trans h₁ h₂ : a = c

数学で等号を並べて $a=b=c$ と書く操作を、二つの保証から一つの保証を作る関数として表している。三つ以上の等式をつなぐときも、Eq.trans の適用を重ねればよい。

congrArg — 両辺に同じ関数を適用する

#check congrArg
congrArg.{u, v} {α : Sort u} {β : Sort v} {a₁ a₂ : α} (f : α → β) (h : a₁ = a₂) : f a₁ = f a₂

f : A → B と h : a = b があるとき、congrArg f h は f a = f b の証明になる。関数 f と等式の証明 h を受け取り、像どうしの等式の証明を返す。

f : A → B
h : a = b
congrArg f h : f a = f b

両辺に同じ関数を適用する、という数学の操作に対応している。この三つの道具は、新しい公理を付け加えたものではなく、Eq の帰納型としての仕組みから証明できるものである。次の左逆の例では、これらを組み合わせて証明を作る。

なぜ等式の性質を証明できるのか

等式には対称性や推移性も必要なはずだが、ここまで出てきたコンストラクターは、反射性 a = a を保証する Eq.refl だけである。ここから他の性質を証明できるのは、Eq を帰納型として定義しているからである。詳しい仕組みは次の章で学ぶが、まず集合の言葉でイメージをつかもう。

集合 $X$ 上の二項関係を $R\subseteq X\times X$ として考える。反射性を満たすには、すべての $x\in X$ について $(x,x)\in R$ でなければならない。したがって、どの反射的な関係も対角集合を含む。

$$\Delta_X=\{(x,x)\mid x\in X\}$$

対角集合自身も反射的だから、反射性を満たす二項関係のうち最小のものは $\Delta_X$ である。これは「同じ要素どうしだけを関係づける」という等号の関係であり、対称性と推移性も満たす。反射性だけを仮定した任意の関係に、対称性や推移性があると言っているわけではない。余分な組を入れない、という最小性が効いている。

関数 $f:X\to Y$ についても、対角上の組 $(x,x)$ は $(f(x),f(x))$ に移り、これは $\Delta_Y$ に属する。したがって、この関係は同じ関数を両辺に適用しても保たれる。いま使った congrArg は、この性質の証明である。

帰納型による定義が与えるもの

上の最小性は、集合の言葉によるイメージである。 Lean では、Eq を帰納型として定義すると、Eq.refl で作る場合を調べることで、任意の等式の証明についての主張を示す原理が得られる。この原理が、余分な場合を持たないという最小性に対応する役割を果たす。

例えば対称性を示すとき、a = b の証明が Eq.refl a である場合を考えればよい。この場合には b も a なので、逆向きの等式の証明も Eq.refl a で作れる。このように、反射性の証明と帰納型の原理を使って、対称性・推移性・関数への適用の性質を証明できる。次の章では、この原理を match で使って三つの性質を証明する。

4. 左逆を持つ写像は単射

写像 $f : A\to B$ に対し、$g : B\to A$ が $g\circ f=\mathrm{id}_A$ を満たすとき、$g$ を $f$ の 左逆という。この条件を各点で書くと、どの $x\in A$ に対しても $g(f(x))=x$ となる。左逆を持つ $f$ は単射であることを示そう。

まず数学の証明を書く

証明。 $x,y\in A$ を任意に取り、$f(x)=f(y)$ と仮定する。両辺に $g$ を適用すると、$g(f(x))=g(f(y))$ となる。$g$ が左逆であることから $g(f(x))=x$、$g(f(y))=y$ なので、

$$x=g(f(x))=g(f(y))=y$$

を得る。したがって $x=y$ であり、$f$ は単射である。∎

先ほどの三つの道具を、この証明に当てはめる

受け取る保証を hgf : ∀ x : A, g (f x) = x と h : f x = f y と名付ける。数学の等号の列に必要なのは、次の三つの証明である。

Eq.symm (hgf x) : x = g (f x)
congrArg g h : g (f x) = g (f y)
hgf y : g (f y) = y

左逆の保証を逆向きにし、像が等しいという保証の両辺に g を適用し、もう一度左逆の保証を使った。これらを Eq.trans でつなげば、要求された x = y の証明が得られる。

道具を適用して、証明の項を作る

Eq.trans を二回使う。まず後ろの二つの等式をつなぎ、その結果を最初の等式とつなぐ。

def injective_of_left_inverse (A B : Type)
    (f : A → B) (g : B → A)
    (hgf : ∀ x : A, g (f x) = x) :
    ∀ x y : A, f x = f y → x = y :=
  fun x y h =>
    Eq.trans (Eq.symm (hgf x))
      (Eq.trans (congrArg g h) (hgf y))

内側の Eq.trans が g (f x) = y を作り、外側の Eq.trans が x = g (f x) とそれをつないで x = y を作る。数学の三つの等号に対応する証明を組み合わせて、要求された型の項を得ている。

左逆の条件そのものをこの場で証明したわけではない。その条件の証明を引数 hgf として受け取り、単射性の証明を返す関数を作ったのである。

✏ 練習

  1. 左逆の証明で使った hgf : ∀ x : A, g (f x) = x と h : f x = f y があるとする。 Eq.symm (hgf x)、congrArg g h、hgf y の型を答え、それぞれが $x=g(f(x))=g(f(y))=y$ のどの等号に対応するか説明せよ。

解答 34

三つの型は次のとおり。

Eq.symm (hgf x) : x = g (f x)
congrArg g h : g (f x) = g (f y)
hgf y : g (f y) = y

並べると、数学の証明の三つの等号になる。 Eq.trans に渡すときには、一つ目の右辺と二つ目の左辺が一致している。

次の章では帰納型を学び、構成子で項を作り、場合分けで使う方法を増やす。証明検査の全体像は、存在などの証明も読んだ後、04_Exists.lean 6節で整理する。

5. 章末問題

四つの題材と rfl を使って、型と証明を確かめよう。

✏ 練習 — 単射と左キャンセル

  1. 三つの単射 $f : A\to B$、$g : B\to C$、$k : C\to D$ の合成が単射であることを示せ。それぞれの単射性を ∀ x y, f x = f y → x = y の形で仮定し、 ∀ x y, k (g (f x)) = k (g (f y)) → x = y の証明を書け。

解答 35

def three_comp_injective (A B C D : Type)
    (f : A → B) (g : B → C) (k : C → D)
    (hf : ∀ x y, f x = f y → x = y)
    (hg : ∀ x y, g x = g y → x = y)
    (hk : ∀ x y, k x = k y → x = y) :
    ∀ x y, k (g (f x)) = k (g (f y)) → x = y :=
  fun x y h => hf x y (hg (f x) (f y) (hk (g (f x)) (g (f y)) h))

最初に hk で g (f x) = g (f y)、次に hg で f x = f y、最後に hf で x = y を得る。外側の写像の単射性から順に使う。

  1. （発展）単射 $f:A\to B$ に対して、写像$L_f:\mathrm{Map}(X,A)\to\mathrm{Map}(X,B)$ を $L_f(u)=f\circ u$ と定めると、$L_f$ も単射である。この事実を Lean で形式化せよ。まず X A B : Type と f : A → B を引数に取り、$L_f$ を leftCompose という名前で定義せよ。次に hf : ∀ x y : A, f x = f y → x = y を仮定し、 leftCompose X A B f の単射性の証明を leftCompose_injective として書け。

ヒント1 — 写像を定義する。 $\mathrm{Map}(X,A)$ に対応する型は X → A である。 leftCompose X A B f の型は (X → A) → (X → B) である。関数 u を受け取り、さらに対象 t を受け取って f (u t) を返す項を書こう。

ヒント2 — 等式を各点で使う。 u、v と、その像が等しいという証明 h を受け取る。関数を対象 t で評価する写像 fun w : X → B => w t を congrArg に渡すと、 h から f (u t) = f (v t) の証明を得られる。それを hf に渡そう。

ヒント3 — 関数どうしの等式に戻す。 各点での等式の証明 k : ∀ t : X, u t = v t から、funext k : u = v が得られる。これを関数外延性という。fun t => … で各点の証明をまとめ、funext に渡そう。

解答 36

def leftCompose (X A B : Type) (f : A → B) :
    (X → A) → (X → B) :=
  fun u => fun t => f (u t)

この写像の単射性を証明する。

def leftCompose_injective (X A B : Type) (f : A → B)
    (hf : ∀ x y : A, f x = f y → x = y) :
    ∀ u v : X → A,
      leftCompose X A B f u = leftCompose X A B f v →
      u = v :=
  fun u v h =>
    funext (fun t =>
      hf (u t) (v t) (congrArg (fun w : X → B => w t) h))

congrArg で得た証明の型は、定義を展開すると f (u t) = f (v t) となる。 hf で u t = v t を得て、各点の証明を funext に渡すと u = v が得られる。

  1. $f : \mathbb{N}\to\mathbb{N}$ について、任意の $u,v : \mathbb{N}\to\mathbb{N}$ に対する点ごとの左キャンセルを仮定する。この仮定から $f$ の単射性を示せ。$u,v$ に定数関数を使うとよい。
   hcancel : ∀ u v : Nat → Nat,
     (∀ t : Nat, f (u t) = f (v t)) → ∀ t : Nat, u t = v t

解答 37

def injective_of_pointwise_cancel (f : Nat → Nat)
    (hcancel : ∀ u v : Nat → Nat,
      (∀ t : Nat, f (u t) = f (v t)) → ∀ t : Nat, u t = v t) :
    ∀ x y : Nat, f x = f y → x = y :=
  fun x y h => hcancel (fun _ => x) (fun _ => y) (fun _ => h) 0

定数関数 fun _ => x と fun _ => y を渡す。それらに f を合成した結果が各点で等しいことは、どの点でも h を返して示せる。 hcancel の結論に対象 0 を渡せば、x = y が得られる。ここでは、前提の証明を返す関数自体も、引数として渡している。

  1. 三つの単調写像 $f,g,k : \mathbb{N}\to\mathbb{N}$ の合成が単調であることを示せ。本文と同じ形で三つの単調性を仮定し、fun と適用だけで証明せよ。

解答 38

def three_comp_monotone (f g k : Nat → Nat)
    (hf : ∀ x y, x ≤ y → f x ≤ f y)
    (hg : ∀ x y, x ≤ y → g x ≤ g y)
    (hk : ∀ x y, x ≤ y → k x ≤ k y) :
    ∀ x y, x ≤ y → k (g (f x)) ≤ k (g (f y)) :=
  fun x y h => hk (g (f x)) (g (f y)) (hg (f x) (f y) (hf x y h))

hf、hg、hk の順に、内側の写像から単調性を使う。それぞれの結果の不等式が、次の単調性の仮定になる。

  1. $f : A\to B$ が単射で、$g : B\to A$ が $f(g(y))=y$ をすべての $y\in B$ で満たすとする。このとき $g(f(x))=x$ がすべての $x\in A$ で成り立つことを示せ。$f$ の単射性を、どの二つの対象に適用すればよいか考えること。

解答 39

def left_inverse_of_right_inverse (A B : Type) (f : A → B) (g : B → A)
    (hf : ∀ x y : A, f x = f y → x = y)
    (hfg : ∀ y : B, f (g y) = y) :
    ∀ x : A, g (f x) = x :=
  fun x => hf (g (f x)) x (hfg (f x))

比べたい二つの対象は g (f x) と x である。それらに f を適用した結果の等式 f (g (f x)) = f x は、hfg (f x) が与える。この証明を単射性に渡せばよい。等号の書き換えをせず、二つの仮定の適用で証明できる。
